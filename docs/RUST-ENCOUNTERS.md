# Rust 试玩版遇敌与训练家对战

游戏规则、地图和对白沿用《火红》。3D 模型、场景和音乐使用本机导入的《Let's Go》资源。草丛仍按《火红》的步进规则触发战斗，玩家可以出招、捕捉或逃跑。

## 已接通的试玩路线

| 地图 | 原版陆上遇敌 | 训练家 |
| --- | --- | --- |
| 1 号道路 | 波波、小拉达 | 店员和男孩只交谈 |
| 2 号道路 | 波波、小拉达、绿毛虫、独角虫 | 以地图事件表为准 |
| 常磐森林 | 绿毛虫、铁甲蛹、独角虫、铁壳蛹、皮卡丘 | 萨米已接通。里克、道格、安东尼、查理需要多只宝可梦的战斗流程 |
| 22 号道路 | 小拉达、烈雀、猴怪 | 劲敌受剧情变量控制，需要多只宝可梦的战斗流程 |

出门前先选初始伙伴。Tab 菜单的 8 控制野生与训练家对战，默认开启。剧情脚本另有开关。萨米在常磐森林西侧，地图坐标为 `(7, 22)`。相邻时按空格，或走进他向西看的视线，他会先说挑战对白，然后派出 Lv.9 独角虫。赢过萨米后再交谈会读到战后对白。当前视线触发直接进入对话，惊叹号和上前动画待补。

## 下一步实现顺序

1. **核对陆上遭遇的覆盖率。** 以 `data/encounters.json` 的地图、地形、权重和等级为准。加一项导入检查，遍历每张可玩的地图和每个合法等级，检查物种、初始招式和战斗显示资源。按实际入口推进至常磐森林、尼比市和月见山。每段至少验证普通地面、草丛或洞穴、换地图、除虫喷雾、捕捉和逃跑。后续再接冲浪、钓鱼和特殊遭遇。
2. **先完成多只宝可梦的单打。** 从固定版本的 `trainers.h` 和 `trainer_parties.h` 导入完整顺序、等级、IV、招式、携带物、AI 标志和奖金倍率。战斗状态保留双方队伍和当前出场槽。倒下时结算该只宝可梦的经验和努力值，按队伍顺序补位，清掉只属于上一个出场槽的临时状态。己方换宠保留 HP、PP 和异常状态。整队打完才写入胜负标志、奖金和存档。以常磐森林为第一批验收，里克 2 只、道格 3 只、安东尼 2 只、查理 3 只。再覆盖 22 号道路劲敌的剧情分支。
3. **补足训练家事件和画面。** 复用同一条战斗入口处理主动交谈和视线触发。按原版事件表检查朝向、有效距离、高度、阻挡、剧情条件以及已战标志。加入惊叹号、接近动作、战败台词和奖励反馈，再扩展到道馆、重赛和双打。验收检查包括格子与自由移动一致、隔墙不触发、战后能正常继续探索，以及重载存档后胜利奖励只发一次。

## 在 Intel Mac 验证

从 `rust-prototype` 目录运行。

```sh
./target/x86_64-apple-darwin/debug/firered-native-prototype --check --logic-only
./target/x86_64-apple-darwin/debug/firered-native-prototype --route --at 6 33 1.5708 --slice-auto --capture /tmp/firered-route1.png
./target/x86_64-apple-darwin/debug/firered-native-prototype --map viridian_forest --at 7 23 3.14159 --music
```

第三条从萨米南侧开始。若队伍为空，先按 2 选小火龙，再按空格交谈。对战尾焰和新增模型可用现有本地 RomFS 重新导入。GlTF、纹理、音乐和 RomFS 都保留在本地。
